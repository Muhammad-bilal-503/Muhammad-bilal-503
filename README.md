## 🛡️ Currently Building: SentinelMesh

**A framework-independent runtime security and governance platform for autonomous AI agents.**

AI agents now read documents, query databases, call APIs and send emails, which opens the door to prompt injection, tool poisoning and data exfiltration. SentinelMesh sits between the agent and its tools, inspecting every call before it executes.

```text
   AI Agent  ──▶  SentinelMesh  ──▶  Tools / APIs / Data
                       │
        identity · validation · permissions
        prompt-injection & PII detection · risk scoring
        policy engine: allow / block / human approval
```

| Component | Stack |
|---|---|
| **SDK & Adapters** | Python · LangChain · LangGraph · CrewAI · AutoGen · LlamaIndex |
| **Security Gateway** | FastAPI · PostgreSQL · Redis · Open Policy Agent |
| **Monitoring Dashboard** | Next.js · TypeScript · Tailwind CSS · React Flow |
| **Attack Laboratory** | Detection rate · false positives · runtime overhead |
